# Seguridad y privacidad

Esta aplicación puede procesar nombres, usuarios, correos, teléfonos y perfiles públicos. En consecuencia:

- no almacenar automáticamente consultas ni resultados;
- no registrar correo/teléfono completos en logs operativos;
- no subir casos reales a GitHub;
- no incorporar mecanismos de acceso autenticado sin revisión independiente;
- no habilitar módulos de reconocimiento activo innecesarios;
- registrar procedencia, fecha y motor de cada hallazgo;
- someter exportaciones a los controles institucionales de acceso y retención.
